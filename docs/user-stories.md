# User Stories — MVP

## Accounts
- As a new visitor, I want to create an account so that I can start my own
  collection.
- As a returning user, I want to log in so that I can access my existing
  shelf.
- As a logged-in user, I want to log out so that my collection stays private
  on a shared device.

## Shelf (empty & populated states)
- As a new user, I want to see an empty shelf with a clear way to add my
  first item, so I understand what to do next.
- As a user, I want my shelf to visually reflect my progress (grayscale →
  colorful) so that building my collection feels rewarding.
- As a user, I want to sort my shelf by name, year, or date added, so I can
  find items the way that makes sense to me.

## Adding items
- As a user, I want to search for a book by title so I can quickly find the
  correct one without typing all its details manually.
- As a user, I want the item's details (author, year, cover) to fill in
  automatically when I pick a search result, so adding items is fast.

## Tracking & reviewing
- As a user, I want to mark a book as read so I can track my progress
  through my collection.
- As a user, I want to rate a book so I can remember how much I liked it.
- As a user, I want to write a short review so I can capture my thoughts
  while they're fresh.
- As a user, I want rating/review/status to be optional, so adding an item
  isn't blocked by having to fill everything in immediately.

## Welcome / first impression
- As a first-time visitor, I want to immediately understand what the app
  does and how to get started, so I don't bounce before signing up.
